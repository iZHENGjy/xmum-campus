# 接下来三个月（2026-11-19 ～ 2027-02）

2026-11-19 和主人聊出来的结论。**开新会话的 AI 先读这一页**，跟这页冲突的提议先问主人。

## 为什么要换做法

- 前几个月靠兴趣撑着，现在兴趣不够撑了。新的支撑是：**被看见、能写进履历、自己在成长**。钱不是重点。
- 数据（`stats` 分支，11-19）：累计 559 人；11-11 那天达到高峰，之后自然回落，最近 7 天 114 人。玩家 76% 的时间在开车，18% 在黑洞。
- 11-12 那份 [roadmap.md](roadmap.md)（「能长期肝的开放世界」、先做任务主线）**不再是当前方向**。

## 三件事

### ① 校园版：低维护
- 只修会坏档、会判错成绩、会打不开的 bug。攒着，每周集中修一次。
- 不再给校园版加新功能、新任务、新小游戏。
- **唯一必须做的事：让数据库备份真正跑起来。** 脚本已经有了（PR #107），还差 GitHub 上的密钥和第一次跑通，见 [backup.md](backup.md)。

### ② 投一个比赛
- 拿**现在的校园版**去投，不为比赛做新功能。能投现成游戏的比赛最早 2027 年 3～4 月才开报名，所以三个月内先把材料准备好，1 月去 Global Game Jam。
- 要准备的：2 分钟视频、一页说明（559 个同学玩过、180 多个 PR、一个人用 AI 做出来的）。
- 比赛、公司名单和顺序：见 [outreach.md](outreach.md)。

### ③ 雪邦：慢慢做，自己的乐趣
- **风格锁死**：以 PR #180 的风格化电影感为准。AI 不许中途换方向，要换只能主人开口。
- **一次一小块**：先做好一段 30 秒，主人说「好」才做下一段。不定截止日期。
- **只给 2～3 个信得过的同学看预览版**，意见收在一处，听不听由主人决定，不是每条都改。

## 不做的事
- 不开新的大功能（雪邦除外）。
- 不追玩家人数：人数回落是正常的，不代表做得不好。
