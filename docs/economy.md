# 经济账：钱从哪来、花到哪去、循环哪里断了

写于 2026-11-12，基于 `dev`（含主线第二期、F1 赛道和围场、天气、英文、好友、手机操作）。
数字的来源：代码里的公式 + 本地离线页里用脚本实测（标「实测」的），不是线上统计。线上统计只有一条：401 个计时玩家里 250 个 5 分钟内离开，70% 时间在「开车 · 奶娃」，23% 在黑洞。

目标循环：**赚钱 → 买车 / 改装 → 比赛 / 挑战 → 排名 / 展示 → 下一个目标 → 回来继续**

**能买的东西加起来约 RM 21 万**（只算一套房子的家具；四套都装满再加约 RM 7 万）。所以「钱没地方花」不是真的没东西卖，而是：

1. **玩家看不到下一件**：车行、衣橱、改装店、房子的「出售」牌子、F1 围场，五个地方各管各的，没有一个地方告诉你「下一个目标是什么、还差多少」。
2. **贵的东西大多是外观**：真正影响手感的只有车、车行改装、改装店的性能件、F1 件，加起来 RM 1.5 万左右，富玩家早就买完了。
3. **改装店卡的是道具不是钱**：一辆车装满要 7 个钛锭、2 个引擎核心、约 20 个涡轮，富玩家钱够、道具不够。

## 3. 零件和材料怎么流动

```
玩法结束 ──XParts.reward(game, grade)──▶ 道具（tune.inv）──┐
  （TN_DROPS：竞速、宿舍、潜入、猴子、黑洞、顺风车、特技…）     ├─▶ 改装店：道具 + RM + 施工时间 ─▶ 车更快 / 更好看 ─▶ 竞速、挑战更好成绩
配方（bp_*）：第一次拿冠军、潜入、宿舍…重复的换成改装图纸 ──────┘
F1 材料（碳纤维布、胶料、风洞数据）：只在围场和雪邦赛道掉 ─▶ F1 赛车 5 件
房子的电竞风家具：也要消耗道具（霓虹、芯片、涡轮…）
```

- 普通道具（轮毂坯件、漆料、霓虹）到处掉，富玩家常常囤几十个。
- 传说道具（钛锭、引擎核心）只从高难度玩法的金牌里掉：宿舍撤离 RM 300+（一定给钛锭）、清空 Bell 通缉榜（一定给核心），其他都是 4–12% 的几率。这是改装的真正瓶颈，也是让玩家回去玩难的玩法的钩子，**这个设计是对的**，不用改。
- 有每日次数的：打卡 1、喷漆 3、特技 8、擦车 6、秋千 6、甩保安 10、顺风车 20、KLIA 12、当面挑战 10。黑洞、竞速、宿舍、潜入、猴子都**没有**每日次数，但要拿金牌才掉好东西。

## 4. 循环在哪里断了

| # | 断点 | 证据 | 影响 |
|---|---|---|---|
| A | **没有「下一个目标」** | 买东西分散在 5 个面板；HUD 只告诉你「到橙色光圈接单」 | 赚了钱不知道干嘛，富玩家只剩刷排行榜 |
| B | **每天回来的理由只有一个**「今日第一单翻倍」 | `prog.daily` 只记这一单 | 一单做完今天就没有新东西 |
| C | **原地转圈是最赚钱的玩法** | 实测 RM 140–280 / 分钟，外卖 90–105 | 最无聊的打法最赚钱，其他玩法显得不值 |
| D | **黑洞模式不进钱** | 占 23% 游戏时间，RM 0 | 和主循环只靠一点零件连着 |
| E | **方程式赛车不算总资产** | 买了以后总资产掉 RM 3,500 | 总资产榜的规则是「买东西不降」，这里破了 |
| F | 被抓罚 30% 现金 | RM 4.4 万现金的人一次罚 RM 1.3 万 | 可能让富玩家不敢开车惹事（没有数据证实）；但也是唯一一个大额回收 |
| G | 新玩家第一次点「开车 · 奶娃」先弹登录卡 | 微信里每次访问都弹 | 还没开始玩就多一次决定，第一次玩什么进度也没有 |
| H | 新玩家要 5 分钟以上才拿到第一笔钱，10 分钟左右才能开车 | 开场过场约 58 秒 + 第 1 章 11 步走路（见第 6 节） | 250 / 401 的人 5 分钟内就走了 |

## 6. 建议（等仓库主人决定，这次**没做**）

### C. 收紧原地转圈（推荐方案 1）
1. **特技现金每天软上限**：每天特技换的钱前 RM 400 照旧，之后 ×0.25。转圈的人一天还能拿 RM 400，之后约 RM 35–70 / 分钟，低于送外卖。改一行：`bankStunt` 里按 `dayKey()` 记当天累计。
2. 或者：同一个地方（半径 30 米）连续漂移超过 20 秒，连击倍数不再涨。更细，但要多调几次手感。

### D. 黑洞给一点钱
第 1 / 2 / 3 名 RM 20 / 10 / 5（一局 150 秒，约 RM 8 / 分钟），只是让它连上钱包；或者不给钱，只靠每日目标里的「黑洞拿前 2 名」（这次已经有了）。**推荐先只用每日目标**，看一周数据再说。

### F. 被抓罚款封顶
罚 30%，最多 RM 2,000。现在 RM 4.4 万现金的玩家一次被罚 RM 1.3 万。封顶后富玩家敢惹事，也就更愿意玩追逐、喷漆这些。代价是少了一个大额回收，靠下面的「愿望清单」补。
