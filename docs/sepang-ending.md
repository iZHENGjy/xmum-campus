## 一句话
雨后黄昏，你戴着赛车手套，坐在 XMUM 满配兰博基尼的驾驶舱里开最后一圈。前半圈路在眼前变形、一大群车抢道乱斗；后半圈安静下来，路变成大学四年走过的地方，最后停在「路在当下」。

## 想让同学有的感觉
感动、有回忆（不是单纯刺激，也不是炫技）。

## 车和驾驶舱
- 车：游戏里 XMUM 的满配兰博基尼，细节加多。现在游戏里的车没有车内，驾驶舱要另外做或用素材。
- 第一人称，完整驾驶舱：方向盘、戴赛车手套的双手、仪表盘、后视镜。
- 车内细节：
  - 后视镜里看到的是上一年；
  - 挡风玻璃上的雨珠，开得越快越往后飞，慢慢干掉；
  - 后视镜上挂着学生证和小奶娃挂件，会晃；
  - 仪表盘屏幕显示“大一 / 大二 / 大三 / 大四”和日期。
- 界面：只在开头给一点操作提示，之后画面上不留东西。

## 一圈 3–5 分钟，四年按顺序，天色跟着变

| | 心情 | 天色 | 节奏 |
|---|---|---|---|
| 大一 | 新鲜又孤单 | 雨刚停，路面反光 | 一大群车抢道乱斗，路在眼前变形（楼倒下、路弹起、桥断掉） |
| 大二 | 有了朋友，很热闹 | 云散开 | 继续刺激，变形更大 |
| 大三 | 压力大、迷茫 | 金色黄昏 | 车群散去，慢下来 |
| 大四 | 不舍，但往前看 | 入夜，路灯亮起 | 几乎停下，只剩回忆 |

速度：前快后慢（前半圈可以全速，越到大四越慢，最后几乎停下）。

## 回忆怎么出现
- 路本身也变：雪邦赛道 → 校园的路 → 吉隆坡的街道 → KLIA 跑道……
- 地方：学校（校门、宿舍、图书馆、建南大礼堂、芙蓉湖）、吉隆坡（双子塔、mamak 档）、KLIA；中间穿插照片（先用占位图，以后主人换成自己的）。
- 路边有看不清脸的朋友人影在挥手。
- 字幕 = 内心独白：中文为主，偶尔混英文 / 马来语。先由我们写一版，主人来改。
- 声音：钢琴或弦乐慢慢起来；经过那些地方时听到那里的声音（飞机、食堂、上课铃）。

## 参考
- 画面：《GT7》的精致写实（尤其驾驶舱和路面）。
- 动作：电影《头号玩家》里赛道在眼前变形、很多车一起乱斗（用我们自己的东西，不用别人的角色）。

## 操作
键盘开车，鼠标在驾驶舱里转头看。只给电脑玩。

## 结尾
「路在当下」出现后，像电影片尾一样慢慢滚过一行“XMUM Class of 2026”，淡出，回到游戏里的校园。

## 不要
玩具赛道、巨型怪物追车、隐藏解法。

## 先说清楚的难点
- 浏览器里《GT7》级别的驾驶舱很难，预计做到它的五六成。
- 前半圈“很多车乱斗 + 路在变形”是最难、最花时间的部分。
- 必须用现成的高质量素材，不能再靠代码拼方块；每个素材的来源和授权先给主人确认。

## 交付顺序
1. 素材清单（来源、授权）→ 主人确认。
2. 只做大一那 30 秒：雨后、驾驶舱、几辆车抢道、路第一次变形 → 视频 + 截图 → 主人满意再往下。
3. 每次交付写清楚改了什么、还差什么。
