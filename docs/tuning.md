# 改装车间

代码：

- `js/42-tuning.js`：道具（分稀有度）、配方、零件目录、各玩法的掉落表 `TN_DROPS`、把零件装到车上、`tuneCarValue()`。
- `js/93-tuning-ui.js`：界面、施工队列、道具发放（`XParts`）、存档、性能加成、总资产。
- `js/94-tuning-drive.js`：开车时的效果：氮气、驾驶技能、尾焰。
- 新车型的模型在 `js/40-vehicles.js`（`gwag` 铁方越野、`moto` 疾风 R 运动摩托），车行列表在 `js/80-gta.js` 的 `SHOP`。

## 玩法

- 买车不用等，改装要等。在「XMUM 车行 → 改装车间」点零件就能在 3D 里预览（拖动转视角，滚轮缩放），上面的四项数值显示**改前 → 改后**。点「下单施工」扣金币、道具，零件进施工位按真实时间计时。
- 存的是完工的时间戳，关掉游戏也照样走。完工时提示一次，车行按钮上挂「可提车」，回改装车间点「提车」就装上。
- 施工中的车照样能开。完工没提车的也占着施工位。默认 1 个施工位，第二个用 RM 800 解锁。
- 新玩家：第一次打开送开张礼包（轮毂坯件 ×3、赛车漆料 ×2、碳纤维板 ×1、霓虹灯管 ×1，老玩家每 4 个成就再送 1 张图纸）。**新手首单 30 秒完工，只限轻改和中改**（这两档本来最长也就 55 分钟）。
  - 改前：第一单不管多高级都只要 30 秒，玩家可以把首单攒着，等材料齐了拿去做 22 小时的赛道级引擎。
  - 改后：高级和顶级照常计时，首单优惠留给下一件轻改或中改。改装车间的提示和零件下面的施工时间都写着「新手首单 30 秒只限轻改和中改」。
- 造好的零件属于那辆车，之后随时免费换装 / 换回原厂。
- 别的玩家能看到你开着的那辆车上的外观改装（尾焰和氮气火焰只有自己看得到）。

### 施工时间（越高级越久）

| 档 | 标签 | 时间 | 例子 |
|---|---|---|---|
| 轻改 | 普通 | 2 到 12 分钟 | 轮毂颜色、前铲、进气 + 芯片调校 |
| 中改 | 稀有 | 20 到 55 分钟 | 单涡轮、半热熔胎、单罐氮气、大尾翼 |
| 高级 | 传说 | 2 到 5 小时 | 宽体、鹅颈尾翼、双涡轮、双罐氮气、37 寸泥地胎 |
| 顶级 | 顶级 | 21 到 22 小时（明天再来提） | 赛道级引擎、直喷赛级氮气 |

加急：金币是前 30 分钟每分钟 RM 12，之后越来越便宜（22 小时约 RM 3,000）；图纸是 `⌈√(剩余分钟 / 20)⌉` 张（20 分钟 1 张，22 小时 9 张）。没有任何真钱加速。

### 属性加成

性能改装开着（`TN_PERF = 1`）。每件零件有 `perf: {acc, maxV, grip, steer}`（比例，`.05` = +5%），装着的零件加起来乘在车的数值上（叠在车行「改装店」的引擎 / 轮胎等级上面）。主要来自「性能」页：

| 槽 | 轻改 | 中改 | 高级 | 顶级 |
|---|---|---|---|---|
| 引擎 | 进气 + 芯片调校 加速 +5% | 单涡轮 加速 +10% 极速 +5% | 双涡轮 加速 +16% 极速 +9% | 赛道级引擎 加速 +24% 极速 +14% |
| 轮胎 | 街道性能胎 抓地 +5% | 半热熔 抓地 +10% 操控 +3% | 赛道热熔 抓地 +16% 操控 +5% 加速 +3% | — |
| 悬挂 | 运动弹簧 操控 +5% | 绞牙避震 操控 +9% 抓地 +3% | 赛道级 操控 +13% 抓地 +5% | — |

外观件也带一点：宽体抓地 +4%、大尾翼 +3%、鹅颈 +5%、钛四出排气加速 +2%、赛道整流罩极速 +5% 等。全改满大约加速 +30%、极速 +15%。

### 技能：氮气、弹射起步、漂移增压（`js/94-tuning-drive.js`）

- **氮气**（「氮气技能」页）：按住 **Shift / N**，手机上按住右下角的「氮气」按钮（和上车、漂移、喇叭在一起）。按钮上有能量条，开着车慢慢回满，漂移和飞跃回得快。喷的时候极速提高 30%~45%、推力大增，车尾喷蓝 / 紫色火焰，有点火声和嘶嘶声，镜头轻微一震。松开以后速度慢慢回落，不会一下子刹住。
  - 单罐（中改）2.5 秒 / 双罐（高级，要配方）4 秒 / 直喷赛级（顶级，要配方）5.5 秒、紫焰、回得最快。
- **弹射起步**（中改，要配方）：停稳以后踩油门，自动猛窜 1 秒，8 秒冷却。
- **漂移增压**（中改，要配方）：漂移结束时按漂了多久推一把（最多 1.6 秒），还给氮气回能。
- 两个技能都是自动触发的，手机上不用多按键。

### 尾焰（「尾焰」页）

- 光轨（轻改）：尾灯拖出两道光带，越快越长，默认尾灯红。
- 火焰尾焰（中改）：排气口一直喷火，光带会闪、从黄烧到红。
- 等离子尾焰（高级，要配方）：一条很宽的发光带加白色内芯，边上飞火星。
- 尾焰颜色：原色 / 冰蓝 / 樱粉 / 电紫 / 酸绿 / 鎏金 / 极光白。
- 天黑以后更亮。画质「流畅」档光带变短、不出火星；尾焰页顶上有「尾焰特效：开 / 关」，关了只是不画，零件还在。
- 实现：一个面向镜头的光带网格（每帧改顶点，一个 draw call），火焰和火星用现有的粒子。改装车间里预览时画一条静止的尾焰。

### 不同车型，不同改法

车型分类 `TN_CLASS`：c 普通车（Myvi、劳斯来斯）、s 跑车（911、玛莎、兰博）、u 越野（铁方越野）、m 摩托（疾风 R）。槽位和零件用 `cls` 限定，改装车间只显示这辆车能装的页和零件（以前造好的零件照样显示）。

| 车型 | 专属的改法 |
|---|---|
| 跑车 | 宽体轮眉、大尾翼、鹅颈双层尾翼（只给跑车），加上前铲、侧裙、扩散器、引擎盖、低趴、外倾 |
| 普通车 | 车身小件、鸭尾、霓虹、低趴；没有宽体和大尾翼 |
| 越野 | 升高 6 / 14 厘米、全地形胎 / 37 寸泥地胎（块状花纹，车身跟着抬高）、车顶行李架 / 行李架 + 灯排、前防撞杠 / 防撞杠 + 绞盘 |
| 摩托 | 排气（高位双出 / 钛蝎）、整流罩（街车裸露 / 碳纤维小翼 / 赛道整流罩加高风挡）、轮圈（细辐 / 锻造 / 碳纤维） |

性能、氮气、技能、尾焰所有车型都能装。

## 哪个玩法掉什么

表在 `js/42-tuning.js` 的 `TN_DROPS`，按档发：0 = 金牌 / 第 1 名，1 = 银牌 / 第 2 名，2 = 铜牌 / 第 3 名，3 = 完成但没名次。百分数是几率，「配方池」是这个玩法的配方里随机一张还没有的。每个玩法的结算界面（结算卡片或结算提示）都会显示这一局拿到的零件；没有结算界面的（秋千、擦车）看 HUD 上方冒出来的零件小条。

随手就能刷的玩法有**冷却**（两次掉落至少隔几秒）和**每日上限**（每天最多掉几次），写在表的 `cd` / `day` 里。只有真掉了东西才算一次；冷却中照样能玩、照样拿钱，只是不掉零件。

原则：
- 每个玩法掉自己的特色件。
- 高频的小玩法只给普通件，有冷却和每日上限。特技连击例外：大连击（2,500 分以上）有几率给胎皮和氮气罐，但每天最多 8 次。
- 传说件和配方多了几条来源，但几率都比难的玩法低：钛锭最稳的来源还是宿舍撤离大丰收（RM 150 以上也有 50%），引擎核心还是清空通缉榜。

## 接口：给玩家发道具

```js
XParts.reward(game, grade, reason)  // 按 TN_DROPS[game] 的第 grade 档发；返回 [{id, n}]，reason 不写就是「玩法名 + 金牌/银牌/铜牌」
XParts.chips(list)                  // 结算卡片用的一排零件小标（HTML 字符串，没掉东西时是空字符串）
XParts.text(list)                   // 「涡轮 ×1、氮气罐 ×2」，放进结算提示
XParts.grant(id, n, reason)         // 发 n 个（默认 1）；id 可以是配方 'bp_…'，已有的配方换成 1 张图纸。返回新数量，id 不认识或 n <= 0 时返回 0
XParts.medal(medal, reason)         // 老接口：按 'arcade' 表发（金 → 涡轮，银 → 碳纤维板，铜 → 漆料）
XParts.count(id) / XParts.has('bp_wide') / XParts.list / XParts.bps / XParts.drops
```

- 每发一次，HUD 上方冒一个小条「+1 碳纤维板 · 猴子大战金牌」；传说零件和配方带金色 / 紫色描边和一串音效。
- 页面里没有 `js/93-tuning-ui.js` 时 `window.XParts` 不存在，调用前判断：

```js
const loot = window.XParts ? XParts.reward('race', place - 1, `竞速第 ${place} 名`) : [];
toast('第 1 名', '+RM 160' + (loot.length ? ' · 改装：' + XParts.text(loot) : ''));
```

- 新玩法：在 `TN_DROPS` 里加一个表（四档），结算时调一次 `XParts.reward`，再把 `XParts.chips` / `XParts.text` 放进结算界面。来源记得补进 `TN_PARTS[].from` 或 `TN_BPS[].from`，背包里会显示给玩家。
- 能随手刷的玩法在表上加 `cd: 秒` 和 / 或 `day: 次`（例：`{name:'喷漆车间', cd:300, day:3, g:[…]}`）。`XParts.reward` 自己会管，记在改装存档的 `lim` 里，过零点重置。
- 额外的一件（比如连胜奖励）用 `XParts.roll(id, n, 几率, reason)`，返回的列表直接接到 `loot` 后面。`XParts.ready(game)` 看这个玩法现在能不能掉（不在冷却、没到上限）。

### 和大胃王争霸赛的衔接（PR #41，`js/minigames/bigeat.js`）

这边没碰那个文件。合并时那边要改两处：

1. `XMini.register` 里加 `parts:'bell'`，删掉它自己的 `XParts.grant('neon', 1)`。
2. 不用再调 `XParts.reward`：B1 的钩子（`js/93-tuning-ui.js` 包在 `mgFinish` 外面）会按奖牌发。

B1 钩子的规则（已经在这边确认过）：

- 游戏声明了 `parts`，而且 `TN_DROPS` 里有这张表，就**只按这张表发，不会再发一份 arcade 表**；没声明或者表名不认识，才按 `arcade` 表发。
- 只在 `mgMedal` 给出金银铜时发：金牌 → `bell` 第 0 档（灯管 ×2、氮气罐、等离子尾焰配方 50%），银 → 第 1 档，铜 → 第 2 档，没牌不发。所以大胃王的奖牌线就是名次线，冠军要对应金牌。
- 零件小标会自动插进 B1 的结算卡片，那边不用写界面。
- 没改之前（它自己 grant 一次，钩子再按 arcade 表发一次），赢一局会拿到「灯管 + 涡轮」两份。

## 改装价值（单辆车）

```js
tuneCarValue('lambo')   // → RM：这辆车现在装着的零件（每个槽一件），按「金币 + 用掉的道具估值」算
```

给「豪车展示区」按「车价 + 改装价值」排序用（车价在 `SHOP[].price`）。改装存档没加载时返回 0。

- 只算车上**装着的**：同一个槽买过好几档（单罐、双罐、直喷）也只算装着的那一件，施工中的不算。这样每个槽的价值有上限，排名不会被「把每一档都买一遍」拉开。
- 总资产（`netWorth()`）还是把买过的全部零件和施工中的都算上，用的是 `tnCarAssets(carId)`。

## 价格和车价

### 改前

兰博鸡尼车价 RM 1,600。全部顶配改装（每个槽最贵的一件）要 RM 20,510 金币，再加上用掉的道具估值约 RM 6,400，改装价值约 RM 26,900，是车价的 17 倍。豪车展示区按「车价 + 改装价值」排，排名几乎只看改装，车价没有意义。

### 玩家一小时赚多少（按代码里的发钱公式估）

| 玩法 | 怎么给钱 | 一小时大概 |
|---|---|---|
| 外卖 | RM 25 + 每 100 米 RM 4 + 剩下的秒数 × 1.2；一单 RM 50~80，连取餐约 2 分钟 | RM 1,500~2,200 |
| 竞速 | 第 1 名 RM 160 × 赛道系数（0.6~1.5），第 3 名 RM 60；一场 2~3 分钟 | 中游 RM 1,000，常拿冠军 RM 2,500 |
| 挑战赛 | 金银铜 RM 70 / 45 / 25，一轮 1~1.5 分钟 | RM 1,500 |
| 教学楼潜入、宿舍撤离、猴子大战 | 一局 RM 100~300，一局 3~5 分钟 | RM 1,500~2,500 |
| 顺风车 | 一单 RM 40~70 | RM 1,500 |
| B1 小游戏 | 有上限（`MG_CAP` RM 60） | 很少 |

**普通玩家混着玩约 RM 1,500 / 小时**（新手 RM 800~1,000，熟手 RM 2,500）。这是按公式估的，没有真人计时。车价：兰博鸡尼 RM 1,600 约 1 小时，劳斯来斯 RM 3,000 约 2 小时。

### 改后

改装金币价格整体调到原来的 25%~45%：越贵的件砍得越多（赛道级引擎 5,200 → 800，直喷氮气 4,200 → 700，宽体 1,200 → 300），轻改只是小降（多辐轮毂 180 → 70）。道具估值也一起调低（钛锭 300 → 80，引擎核心 500 → 120，配方 200 → 60），不然光道具就有车价的 4 倍。

| 车 | 车价 | 顶配金币 | 改装价值（金币 + 道具） | 改装价值 / 车价 | 车价 + 改装价值 |
|---|---|---|---|---|---|
| 劳斯来斯 | 3,000 | 4,265 | 5,803 | 1.9 倍 | 8,803 |
| 铁方越野 | 2,200 | 4,345 | 5,899 | 2.7 倍 | 8,099 |
| 兰博鸡尼 | 1,600 | 4,765 | 6,407 | **4.0 倍** | 8,007 |
| 玛莎拉弟 GT | 900 | 4,765 | 6,407 | 7.1 倍 | 7,307 |

| 疾风 R 摩托 | 1,100 | 3,780 | 5,266 | 4.8 倍 | 6,366 |
| Myvi | 60 | 4,265 | 5,803 | 97 倍 | 5,863 |

- 兰博鸡尼正好 4 倍，劳斯来斯和越野在 2~3 倍。便宜车的倍数高，是因为所有车共用一张价格表；这是有意的：满改 Myvi 是个梗，但它在展示区还是排在满改的贵车后面。
- 两辆都满改时，车价决定排名（劳斯来斯 > 越野 > 兰博）；同一辆车比的是改了多少。
- 「改装店」的引擎 / 轮胎等级（`js/80-gta.js` 的 `UPG`，全买约 RM 3,670）和第二个施工位（RM 800）不算改装价值，这次没动。
- 加急价格没动（22 小时约 RM 3,000）：金币不再是瓶颈以后，加急就是主要的金币去处，用 2 小时的收入省掉一天的等待。

### 满改要玩多久（兰博鸡尼）

| | 需要 | 大概要多久 |
|---|---|---|
| 金币 | RM 4,765 | 约 3 小时（改前 RM 20,510，约 14 小时） |
| 普通、稀有道具 | 碳纤维 ×19、灯管 ×12、涡轮 ×9、轮毂坯件 ×8、氮气罐 ×7、胎皮 ×4、避震 ×3 等 | 和金币一起玩出来，3~5 小时 |
| 传说道具 | 钛锭 ×6、引擎核心 ×2 | 钛锭约 1 小时 1 个（宿舍撤离大丰收必出，其他玩法 5%~12%）；核心靠清空通缉榜、期末卷 25%。合计 6~10 小时 |
| 配方 | 宽体、鹅颈、赛道引擎、氮气系统、弹射起步（或漂移增压）、等离子 | 跟着上面的玩法出，最慢的是宽体和鹅颈（宿舍撤离配方池） |
| 施工 | 合计 68 小时，其中两件顶级各 21~22 小时 | 两个施工位不停也要 34 小时，实际 2~3 天 |

结论：满改一辆跑车大约要玩 **8~12 小时，跨 2~3 天**。卡住进度的是传说道具、配方和施工时间，不是金币。

## 竞速的平衡（`js/92-racing.js`）

- **人机赛**：AI 的极速和加速本来就是按你这辆车（含改装）的数值乘一个系数，所以性能改装越高，AI 也越快，难度不变。你装了氮气时，AI 也会在直道上隔十几秒喷一次（`rcAiDrive` 外面包了一层）。
- **用了氮气或技能的那一场不上榜、不存影线**（`RC.nos`），结算卡片上写「用了氮气或技能，这场不上榜」。排行榜和影线只比车和车手；性能改装算车的一部分（排行榜本来就不分车型）。
- **道具赛**本来就不上榜，氮气随便用。
- 开赛时有一条提示告诉玩家这条规则。

## 加零件

在 `js/42-tuning.js` 的 `TN_ITEMS` 里**往对应槽的末尾**加一行。联机外观字符串（`/looks` 里的 `tk…`）按「槽的顺序 + 零件在槽里的序号」编码：

- 槽只能加在 `TN_SLOTS` 的末尾，零件只能加在槽的末尾，不能删、不能调顺序，否则别人看到的会错位。
- 每个槽一个 36 进制字符，所以一个槽最多 36 件；现在 30 个槽，字符串 32 个字符，`/looks` 的 120 字符上限够用。
- 新的外形要在 `tnBody`（车身件）、`tnMoto`（摩托件）或 `tnWheelGeo`（轮毂、越野胎花纹）里画出来。普通车、跑车、越野车的位置由 `tnAnchors` 用射线从车身外壳上量出来（越野车的车顶行李架用量出来的 `roofY`）。

## 总资产

`assetSource('carmods', …)`：造好的全部零件和施工位里的零件按「金币 + 用掉的道具估值」（每辆车的 `tnCarAssets` 加起来，比 `tuneCarValue` 多算了没装着的和施工中的），背包里的道具按估值，配方每张 RM 60，第二个施工位 RM 800。下单只是把现金换成零件，总资产不变；加急花的钱和图纸不算资产。

## 联机

开着自己的车时，`XWard.lookStr()` 后面多一段 `tk` + 每槽一个字符（共 32 个字符），总长超过 120 就不带这段。`js/net.js` 画别人的车时调 `tnApply(c, tnFromToken(look))`，摩托和越野车也一样。字符只用 `[a-z0-9]`，现有的 `/looks` 规则就能通过，**不用重新发布数据库规则**。
