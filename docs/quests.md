# 主线任务书（草稿，2026-11-12）

**奶蛙的大一：从南门报到，到去 KLIA 接下一届新生。**

七章主线，大约 6 小时；每个人机奶蛙还带几条支线。每一步都用游戏里现成的玩法。

- 第 1 章走路完成，顺便学操作，做完才能开车。
- 小火车、汽车游乐园的比赛跟着主线解锁，其他地方都开着。
- 主线就放在游戏指南（P）的第一页。

背景和优先级见 [roadmap.md](roadmap.md)。

## 已经定下来的

- **第 1 章做完前不能开车**：上车、抢车、搭顺风车都不行，靠近车时提示「先跟小满学姐报到」。第 1 章最后一步，小满把一辆 Myvi 的钥匙交给你。
- **第 1 章送外卖久一点**：
  - 要送 5 单，全用走路送。
  - 只派校园里的单，时限 ×1.5。
  - 多给的时间算宽限，报酬不变（`js/50-missions.js` 的 `grace` 本来就这么算）。
  - 参考速度：现在的时限按开车 13 米/秒算；奶蛙走路 5.5 米/秒，跑步 11 米/秒（`js/40-vehicles.js`）。
- **主线就是游戏指南 P 的第一页，做成「奶蛙日记」**：不另做主线面板。日记旁边贴着妈妈和小满学姐发来的手机消息。每一步旁边有「看说明 ›」，跳到指南里对应的旧页面（`XGuide.open(页)`）。
- **名字**：主角叫「奶蛙」，青蛙的蛙。游戏里现在的文字和代码注释大多写的是「奶娃」（约 220 处），要不要统一改还没定。
- **老玩家补发**：跳过的章节和支线，奖励一次补发。
- **上锁只有两处**：汽车游乐园的比赛（第 5 章开始时解锁），小火车（第 7 章开始时开通）。

## 故事线

坐奶蛙航班飞到吉隆坡，大巴进校（开场过场）→ 报到（身上只有几十块，走路送外卖）→ 打工（拿到车钥匙，自己挣钱）→ 期末周 → 校外（认识雪邦）→ 车手（改车、跑雪邦赛道）→ 安家 → **去 KLIA 接下一届新生，你成了学长学姐**。

首尾呼应：第 1 章是小满学姐带你，第 7 章轮到你把新生接回学校。以后的布城、吉隆坡 DLC 接在后面当第 8、9 章。

## 过场动画

三段像电影一样的过场，插在主线里。用到的东西游戏里大多已经有了：

- 奶蛙航空的黄色客机（`js/16-ambient.js`，现在每隔几分钟从校园上空飞过）
- KLIA 航站楼场景（`js/89-klia.js`）
- 校巴模型（`js/40-vehicles.js` 的 `bus`）
- ERL 坐车过场的导演代码（`js/89-train.js`：分段、机位、牵着奶蛙走、随时跳过）

这些过场共用一个小工具 `js/89-cine.js`：上下黑边、字幕、心里独白气泡、机位、「跳过」按钮和 Esc。过场都随时能跳过，P 的主线页里能「重看开场」。

### 想家：抬头看飞机

做主线的路上出现，约 6 秒，一句话。

- **什么时候出现**：奶蛙航空的客机正好飞到头顶附近，而且这时：
  - 奶蛙在室外走路，没开车；
  - 没在限时送单、比赛或被保安追；
  - 主线进行中，在两步之间（刚完成一步，或正走向下一步的地点）。

  第 1、2 章里保证至少碰到一次；之后最多一天一次。
- **画面**：
  - 上下黑边滑进来，声音和电台调小；
  - 奶蛙停下、抬头，镜头跟着慢慢往上转，看黄色客机拖着两道白线飞过；
  - 屏幕中间浮出一行心里独白（斜体、没有名字、和对话框不一样）：**「……我想家了。」**
  - 两三秒后镜头落回来，黑边退掉，接着玩。

  按任意键或点屏幕立刻结束。
- **以后几次的独白**可以换着来：「不知道家里现在几点了。」「好想吃妈妈做的饭。」「下次放假，坐那班飞机回去。」
- **晚上**客机只看得见闪着的航行灯，独白换成「家那边，现在也是晚上吗？」
- **性能**：客机本来就在飞，只是多了镜头动作和一行字，零额外开销。

### 结尾：轮到你接新生

第 7 章最后一步，约 45 秒，和开场对称。

KLIA 到达大厅，这次是你举着「XMUM 新生」小旗。一只刚下飞机的新生奶蛙东张西望。同样的大巴、同样的油棕树，只是坐窗边看着「哇~~」的换成了他。最后一个镜头：南门，你把他交给小满学姐，奶蛙航空的客机正好从头顶飞过，这次奶蛙抬头笑了一下。字幕：「第一年，完。」

## 怎么展示、怎么引导

原则：不另开新面板，不挡视线，都放在玩家已经熟悉的位置。正在送单或比赛时，主线自动让位。

1. **任务条**：右上角钱包面板，送单那一行下面多一行，比如「主线 1/7 · 走到 A3 大台阶 · 1/9」。点一下（或按 P）打开指南的主线页。
2. **指南针**：屏幕顶上那个，没在送单或比赛时，指着主线的下一个地点并写上距离。有外卖、挑战、比赛时先指那些，主线排最后。
3. **小地图和大地图**：主线目标画一颗黄星，有任务的人机奶蛙画黄色「!」。大地图（M）的图例加「主线」。
4. **人机奶蛙**：
   - 头上的黄色「!」：有新章节或支线。
   - 「…」：进行中，再去说话会提醒你下一步。
   - 没有事时就只站着，偶尔做个表情。
   - 走近了写「F 说话」，手机上是头顶的按钮。
5. **地上的黄圈**：「走到某处」这种步骤，在目标地点画一个黄色光圈，和外卖的橙圈、挑战的蓝圈区分开。
6. **完成提示**：每完成一步，用现有的小提示条（`#gxcall`）显示「✓ 打开了大地图 · +RM 10」。一章做完用成就那种大卡片（`#gxach`），列出奖励，然后回去找人机奶蛙听结尾。
7. **操作提示**：
   - 电脑：屏幕下方显示按键提示，比如「`M` 打开大地图，找到 D6 食堂」。
   - 手机：不写按键，让对应的按钮闪一圈黄边（小地图、F 按钮、跑步摇杆）。
   - 做完就消失，每个提示只出现一次。
8. **对话框**：
   - 屏幕下方一块，左边头像，右边名字和一句话。
   - 空格 / 点一下翻下一句，Esc / 「跳过」直接跳过。
   - 对话时游戏不暂停，但奶蛙站住不动（和接单卡片一样）。
9. **指南 P 的主线页 = 奶蛙日记**（详细见下一节）：
   - 每一章是一页日记，上半页是奶蛙写的几句话，下半页是「今天要做的事」（☑ 做完 / 高亮 现在这步 / ☐ 还没到）。
   - 现在这步展开写操作提示，电脑和手机分开写。旁边「看说明 ›」跳到对应的旧页面：

     | 章节 | 跳到的旧页面 |
     |---|---|
     | 第 1 章 | 按键速查、看地图、欢迎 |
     | 第 2 章 | 赚钱的门路、保安、改装 |
     | 第 3、4 章 | 赚钱的门路 |
     | 第 5 章 | 改装、零件和配方 |
     | 第 6 章 | 买房装修、总资产 |
     | 第 7 章 | 赚钱的门路里的「坐小火车」 |

   - 支线在日记后面的「便利贴」页，再往后翻是原来的各页。
   - 第一次进游戏的提示从「按 P 看游戏指南」改成「按 P 看日记」。
10. **不想被打扰**：日记页底下有个开关「收起任务条和提示」。关掉以后只留指南针，主线照样记进度。

## 故事指引：奶蛙日记（借一点手机消息）

按 P 打开的第一页就是奶蛙日记。以日记为主，再从「手机聊天」那个方案里借一点：日记旁边贴着这一天收到的手机消息，不做整套聊天界面。

### 一页日记长什么样

- **页眉**：「开学第 N 天 · 天气」和章节名。N 是玩家真正上线玩过的天数，天气跟着游戏里现在的天气（晴、黄昏、夜晚、下雨）。
- **日记正文**：奶蛙第一人称，几句话，口语，带点情绪。不是一次写完的，事情发生了就往下添一句：
  - 一章开始：写人机奶蛙交代了什么（「小满学姐塞给我一个工作牌，说先走路把学校认熟。」）。
  - 一些「第一次」：第一次被保安抓、第一次飞进湖里、第一次差点送单超时，各一句（「送第一单外卖的时候差点迟到，跑得腿都软了。」）。
  - 想家那一幕：自动记一句（「傍晚有一架黄色的飞机从头顶飞过去……我想家了。」）。
  - 一章结束：一句总结，然后翻到新的一页。

  句子都是写好的模板，填进地点、车名、钱数，不用现场生成。每章大约准备 6–10 句。
- **今天要做的事**：这一章的步骤清单，做完的划掉，现在这步高亮，展开写操作提示和「看说明 ›」。
- **右边贴着手机消息**（手机竖屏时排在日记下面）：这一章里收到的消息，最多显示最近 3 条。
- **翻页**：往前翻是已经写完的章节（开场那页写「飞往吉隆坡」），隔几天回来的老玩家翻一翻就知道上次写到哪儿；往后翻是「便利贴」（支线），再往后是原来的游戏说明各页。开场那页有「重看开场」。

### 手机消息

谁会发消息：妈妈、小满学姐，以后可以加别的人机奶蛙。消息不用回，看就行。

- **在游戏里**：收到消息时，屏幕右上角弹一个小通知（图标、名字、一句话），3 秒后收起，不挡操作。正在过场、比赛、被追的时候先攒着，结束了再弹。
- **在日记里**：贴在这一章那页的右边。

妈妈的消息（什么时候发 → 内容，同一条只发一次）：

| 什么时候 | 消息 |
|---|---|
| 开场结束，到南门 | 到学校了吗？到了跟妈说一声。 |
| 想家那一幕之后 | 刚看了天气，雪邦下雨了吗？记得带伞。 / 视频吗？你爸也在。 |
| 拿到车钥匙、第一次开车 | 开车慢点！！ |
| 第一次被保安抓 | 学校怎么打电话来了？？ |
| 第 3 章期末周 | 考试加油，别熬太晚。 |
| 真实时间凌晨 1 点以后还在玩 | 这么晚还不睡？ |
| 买下第一套房 | 你哪来的钱买房？？ |
| 第 7 章结尾 | 一年了，长大了。放假回来妈给你做好吃的。 |

小满学姐的消息：主要是提示。比如一步卡了 10 分钟还没做完，她发一句「D6 食堂门口有橙色圈圈，从那儿接单最近」。每一步最多提示一次。

### 存档

日记不存整段文字，只存「哪些句子、哪些消息已经出现过，填了什么值」，比如 `{s:'deliv_late', d:1}`、`{m:'mom_car', d:3}`。和主线进度一起放在 `xmum-quest-v1`，打开日记时再拼成文字，所以存档很小。

## 现有玩家怎么接上

正式版已经有 400 多个玩家，有人攒了几万块。主线上线那天，不能让他们觉得「被重置了」或「被拦住了」。

### 谁算老玩家

本机 `xmum-gta-v1` 里有任何进度（钱 > 0、送过单、买过车、有成就），或者 Google 登录拉回来的云存档里有进度。新开的浏览器、什么都没玩过的才算新玩家。

### 第一次打开新版本

- **不播开场，不锁车，出生点照旧**（自家房子，或者原来的位置）。正在开车的照样在车上。
- 进游戏几秒后，小满学姐的欢迎卡弹一次：「欢迎回来！学校新开了主线，你已经完成了第 1–N 章。补发：RM X + 道具。」卡片上两个按钮：「翻翻日记」「看开场」，也可以直接关掉。
- 自动打勾：每一章里现成条件那几步都满足了，标「新」的那几步也算完成。所以老玩家通常直接停在第 5 章（汽车游乐园）或第 6 章（买房）开头。汽车游乐园、小火车本来只在预览版里有，正式版的老玩家没玩过，所以这样排正好。
- **日记补写**：前面跳过的章节每章补一句总结，页角写「补记」。比如「（补记）那时候刚来，走路送外卖，跑得腿都软了。」日记一打开不会是空的。
- 补发的钱一次进钱包，所有老玩家的总资产会一起涨一点（最多约 RM 5,000）。发布说明里要写清楚，免得大家以为排行榜出错了。

### 云存档和多台设备

现在的云存档是「整份存档二选一」：`js/net.js` 的 `blobScore()` 算哪边进度多，就用那一边整份覆盖另一边，然后刷新页面。主线存档 `xmum-quest-v1` 也是 `xmum-*` 键，会跟着一起同步。所以：

- **迁移和补发要等云同步做完再开始**（`XNet.ready` 之后、`cloudSync()` 结束）。不然刚补发完就被云端旧存档盖掉，或者两台设备各补一次。
- 整份二选一意味着补发不会重复领：赢的那一份里只有它自己那一次补发。领过的奖励 id 记在 `xmum-quest-v1` 里，再打开也不会再发。
- `blobScore()` 要把主线进度算进去（比如每章 +300）。否则一个新玩家在手机上做到第 3 章，云端却是电脑上钱稍多一点的旧存档，手机的主线进度就被盖掉了。

### 其他

- 人机奶蛙不是联机玩家：不进在线人数、不能被当面互动（`XSocial`）、不上传位置。
- 预览版的存档有 `xmum-preview:` 前缀，和正式版分开。预览版测试模式里加「模拟老玩家存档」「清空主线进度」两个按钮，方便测迁移。
- 浏览器还缓存着旧 JS 的人，在发布时 `?v=` 加一后会拿到新版。

## 做法

- **每一步怎么算完成**：大部分是现成的成就和计数，比如 `prog.ach.deliv1`、`owned.has('myvi')`、`netWorth() >= 5000`。每半秒查一次，不用改各个玩法的代码。标了「新」的十来步要加一个小钩子。
- **第 1 章不能开车**：上车、抢车、搭车的地方先问主线，没做完时提示「先跟小满学姐报到」。
- **老玩家**：见上面「现有玩家怎么接上」。
- **两处上锁**：
  - 汽车游乐园：第 5 章开始前，雪邦赛道计时（`sepLap`）、8 字赛道计时（`parkLap`）、大跳台和回环纪录都不开始，能进去随便跑。地图上那 5 条格子旗赛道不受影响。
  - 小火车：第 7 章开始前，`js/89-train.js` 的上车提示写「主线第 7 章开通」。站厅照样能进去逛，火车照样开过。
  - 预览版测试模式（`js/preview-cheats.js`）加「主线全部解锁 / 跳到第 N 章」，方便测。
- **手机性能**：人机奶蛙用玩家同款的 `makeNaiwa()` 加衣橱配件，60 米外隐藏，手机上不投影子。不连网，零流量。
- **存档**：`localStorage 'xmum-quest-v1'`，存第几章、哪些奖励领过；Google 登录的人会跟着其他 `xmum-*` 键一起云同步。
- **文件**：新文件 `js/89-quest.js`（数据、判断、人机奶蛙）和 `js/89-quest-ui.js`（任务条、对话框、指南主线页）。放在 `89-train.js` 后面、`ui-guide.js` 前面加载。
- **过场**：新文件 `js/89-cine.js`，放在 `89-quest.js` 前面。开场要新做的只有机舱和带队老师，大约两三天；「想家」半天。
- **分两批做**：第一批做框架、开场过场、「想家」、第 1–3 章、两处上锁、老玩家补发；第二批做第 4–7 章、结尾过场和支线。

判断条件都对照过 `dev` 分支的代码：成就表在 `js/80-gta.js` 和各玩法文件的 `achAdd`，计数在 `prog.life` / `prog.best`，车在 `owned`，总资产在 `netWorth()`，外卖时限在 `js/50-missions.js` 的 `missionOrder`。
